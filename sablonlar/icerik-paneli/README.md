# İçerik, yönetim ve medya starter kaynağı

Bu dizin creator girdisidir; doğrudan var olan projeye yapıştırılmaz.
[Versioned0.8 rehberi](../../docs/versioned/0.8/icerik-paneli.md) yeni private
hedefe creator, açık DB göçü, PHC ve local TLS adımlarını verir.

SQL içerik CRUD, native admin/session/CSRF, raw upload ve bounded image→PNG
pipeline mevcut dilde yazılmıştır. Binary cevap owned Python host'undur.
DB+FS saga ve durable pending/explicit operator review gerekir; orphan veya
unknown otomatik temizlenmez/replay edilmez. Genel CMS/production deploy,
novice30min veya gerçek ürün/P08 kabulü diye sunulmaz.
