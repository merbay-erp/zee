# Spesifikasyon

Resmi spesifikasyon **korpustan sonra** yazılır: grammar 30 golden programdan
çıkarılır (master plan bölüm 5), burada EBNF + kural metnine dönüşür.

Kapsam (master plan bölüm 23): lexical/Unicode kuralları, EBNF grammar, ad
çözümleme ve scope, tür sistemi, evaluation order, numeric overflow,
memory/resource semantics, concurrency/cancellation, error model,
module/package resolution, FFI/ABI, stdlib stability, deprecation politikası.

Şu an tek bağlayıcı içerik: [kararlar/gunluk.md](../kararlar/gunluk.md)'deki
`geçici` kararlar ve MANIFESTO.md ilkeleri.
