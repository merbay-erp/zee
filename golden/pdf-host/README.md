# Sabit owned PDF backend örneği — K-275 dar host profili

ana.dil mevcut Metin sözlüğünü mevcut JSON serializer ile yazar. Ayrı host aracı job.json'u alır. Bu bir compiler PDF intrinsic/FFI veya signed plugin değildir. B3 kökeni PRODUCT-PROVENANCE.json; özel ürün kodu/gövdesi kopyalanmaz. Assets tamamen anonim teknik fixture'dır. Mevcut pages3 -> selected2 + generated1 -> catalog3; all seçeneği selected3/catalog4. Mevcut sayfa content operators ve render pixel'leri korunur; bütün kaynak PDF baytları veya imzalar korunuyor denmez.

Operatörün seçtiği Python runtime ReportLab4.4.9/pypdf6.10.0/Pillow12.3.0 taşımalıdır. Backend bu üç dependency sürümünü parser çağrısından önce exact denetler. Proje lisansı ertelenmiş kalır; üçüncü taraf fontun özgün COPYRIGHT-DejaVu.txt ve LICENSE-DejaVu.txt metinleri fontla birlikte saklanır, kaynak/name-table çıkarım zinciri FONT-PROVENANCE.json içindedir. Binary değişmedi; paket metadata BSD etiketi bu tam bildirimleri ikame etmez. Host yalnız kodda sabit hash'i bilinen base.pdf/font.ttf/product.png kaynaklarını açar. Kullanıcı PDF/path/font/HTML/URI almaz. Çıktı yeni owned dizindedir; hata2 fixedJSON, mevcut dizin korunur; çok dosyalı atomik publication yoktur. Job8192B, assets/output1MiB, en çok4page, fixedcontrols. Operatör güveni ile hostile PDF sandbox'ı farklıdır.

Recipe: trusted existing dil çalıştır ana.dil > job.json; <operator-selected-python> -I -B scripts/pdf-katalog-host.py --fixture-root <this-directory> --job job.json --output <fresh-directory>. Komutlar ayrı sahipçe yürütülür, Zee içinden shell çağrısı yoktur. `scripts/tests/pdf-backend-acceptance.py` sekiz host backend vakasını yürütür; temiz platform, fullP11/P08, gerçek ürün backend değişimi, resmi imzalama ve canlı SMTP kabulü açık kalır.

Normal test: python3 -I -B scripts/tests/pdf-job-validation-test.py (stdlib8/POSIX). Dedicated opt-in: operator-selected exact backend Python -I -B scripts/tests/pdf-backend-acceptance.py --framework-root <root> --output <fresh>. Bu ayrı ownedbackend8 normal Cargo bağımlılığı değildir; `compiler/tests/pdf_host_testi.rs` normal stdlib ve explicit ignored backend sarmalayıcılarını ayrı tutar.
