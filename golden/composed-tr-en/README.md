# Anonim bileşenli TR/EN uygulama

K-289 / ADR-147. Gerçek Zee görünüm blokları ve uygulama fonksiyonları;
HTML metin birleştirmesi yok. Altı rota, iki katalog dili, aynı bağlantı
partial'ını kullanan gezinme/liste, ayrı detay ve kapalı named layout slotları.
Ayrıntı ve güven sınırı: [bileşim rehberi](../../docs/composed-tr-en.md).

K272 ve özel ürün kaynağı değiştirilmez. Bu fixture anonim uygulamadır;
özel ürün kullanımı veya yeni built-in template/çeviri grammar'ı değildir.
