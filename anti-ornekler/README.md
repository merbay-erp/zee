# Anti-örnekler

Dilin **olmayacağı** şeyler. Her dosya: reddedilen biçim + neden reddedildiği +
doğru karşılığı. Bunlar compile-fail korpusunun ilk tohumudur — parser bu
biçimleri ya reddetmeli ya da (işaretlenen birkaçında) öğretici Türkçe hata
mesajıyla yönlendirmelidir. İlgili ilke: MANIFESTO.md dört soru süzgeci.
