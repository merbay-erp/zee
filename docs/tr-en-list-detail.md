# K-272 — tam TR/EN HTTP golden kapasitesi

Ayrı [golden proje](../golden/tr-en-list-detail/README.md), mevcut K249 plain Metin named-slot ve çeviri helper yaklaşımıyla altı sabit TR/EN liste–detay GET rotasını tam typed HTML document olarak çalıştırır. Eski K249 fragment/main7+4 davranışı byte-eş korunur. Yeni compiler veya generic HTML slot/layout sistemi yoktur.

Dış aday actual native kampanyasında9 HTTP,5 Zee ve eski7+4 korunumu geçti; exact source/binary/helper/snapshot kimliği actual dirty bilgisiyle kayıtlıdır. Ortak Cargo/fullphase ve temiz final kabulü root tarafından ayrıca alınır. Golden proje yeni dogfood/P08 ürün kaydı değildir. Gerçek anonim ürün sayfası/adoption, genel i18n/plural/locale/RTL, arbitrary component body slot ve diğer platformlar açık kalır.

Kullanım, HTML güvenlik bağlamı, kayıt sınıfı ve exact C4 provenance için golden README’ye; scoped karar için [ADR130](../adr/130-sabit-tr-en-liste-detay-http-golden.md) bakılır.
