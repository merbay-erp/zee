# K-300 dar kabul özeti

[ACCEPTANCE.json](ACCEPTANCE.json), özgün dış makbuzların türetilmiş özetidir;
özgün makbuz veya yeniden çalıştırılmış kabul değildir. `E` dış kanıt kökünü
ve her makbuzun exact hash/baytını kaydeder. Runtime proje/.zee içeriği okunmadı
ve arşivlenmedi. Son belge kapısının gerçek dış makbuzu ayrıca gereklidir.

[Koşucu rehberi](../../../mixed-revision-wave.md) ve
[ürünleşme raporu](../../../urunlesme-k298-kabul-20261016.md) kapsamı açıklar.
